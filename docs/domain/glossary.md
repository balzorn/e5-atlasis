# Domain Glossary

| Term | Definition |
|---|---|
| Information Asset | Unified domain entity representing an Information System or Information Infrastructure Object |
| Information System | Information asset classified as an information system |
| Information Infrastructure Object | Information asset classified as an infrastructure object |
| Asset Version | Immutable snapshot of an Information Asset state |
| Change Request | Controlled request to change Information Asset fields |
| Field Change | One proposed change of one Information Asset field |
| Discussion Thread | Discussion associated with a Change Request or specific Field Change |
| Approval | Explicit decision required for a Change Request |
| Organization | Holding organization owning or operating an Information Asset |
| Owner | Responsible person for an Information Asset |
| Criticality | Business significance of an Information Asset |
| Risk Level | Current assessed security risk level |
| Protection Status | State of the required information protection measures |
| Attestation Status | State of attestation/certification requirements |
| Cyber Center | Holding cybersecurity center interacting with the Information Security service |
