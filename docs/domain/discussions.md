# Discussions

Discussions provide contextual communication for Change Requests.

## Discussion Thread

A thread belongs to one Change Request.

A thread may be:

- general discussion for the Change Request;
- discussion attached to a specific Change.

## Thread Status

- OPEN
- RESOLVED

## Comment

A comment belongs to one thread.

Comments contain:

- ID
- author
- body
- created_at
- updated_at
- deleted_at

## Rules

1. A resolved thread cannot receive new comments.
2. A thread must be explicitly reopened before continuing discussion.
3. Comments are never physically deleted.
4. Editing a comment does not remove its audit history.
5. No nested comment hierarchy is used; replies are comments in the same thread.
